# DataMax V3 Plan Archive

Files in this directory are historical design, execution or validation evidence. They are not executable plans.

Rules:

- The only current entry point is `docs/plans/datamax-active-execution-plan.md`.
- Do not resume an archived Task number or inherit an archived approval ID, SHA baseline, provider window, feature-flag scope or deployment command.
- Paths and status statements inside an archived body describe the repository at that historical time and may now be stale.
- Missing checkmarks in an archived template do not automatically become current backlog.
- A current requirement must be copied into the unique active dated plan with a new task number, dependencies, tests and completion standard before execution.
