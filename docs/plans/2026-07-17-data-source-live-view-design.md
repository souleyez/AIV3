# 数据源动态视图设计

## 目标与边界

数据源页改为“主数据区 + 右侧接入方式竖栏”。主数据区把已经归档到数据集的资料视为可浏览的数据源，展示真实字段提示、数量、解析状态和最近变化；右侧竖栏保留六种接入方式及状态。用户可以给每个数据源设置一个只用于当前浏览器查看的显示名称。该名称写入 `localStorage`，不修改数据集标题、文档标题、数据库连接名、检索范围或同步配置，也不新增后端命名接口。

## 页面结构

左侧首先显示“动态导入监测”。数据源按数据集聚合成卡片，并按最近文档更新时间倒序排列。每张卡片显示本地显示名、原始归档名称、文档数、预估字数、内容类型、字段提示、解析状态、最近更新时间和近 24 小时变化数；展开后显示最近变化的资料。字段提示只取现有数据集摘要中的名词、章节和材料提示，不虚构业务字段。数据库源区继续使用真实状态接口，补充字段名与类型展示；同步处于运行态时只轮询状态，不重复扫描 schema。

页面每 60 秒低频刷新一次文档列表，并在标签页不可见或已有刷新进行中时跳过。动态圆点、时间文字和运行态都绑定真实加载状态、同步状态和更新时间，不显示模拟百分比或虚假新增行数。右栏在桌面端保持竖列和粘性定位；窄屏回落为普通单列。

## 数据流、异常与验证

纯视图模型负责把 `datasets + documents` 聚合成数据源卡片，计算字段提示、解析计数、最近变化和排序，便于单元测试。组件只负责别名编辑、定时刷新和渲染。浏览器存储不可用时仍显示原始数据集名称，并把别名编辑降级为当前页面状态。文档刷新失败沿用现有全局提示；数据库 schema 或 status 失败沿用现有错误卡，不影响其他数据源浏览。

验证包括：视图模型单测、现有数据库源单测、Web 构建、桌面与窄屏浏览器检查，以及部署后在 `doc.elepcloud.com` 验证右栏、别名、字段、数量和最近变化。
