资源排队

效果图生成需要排队，可以联系商务开通高级用户跳过等待。

1. 规划态

模型先给出整页规划：模块标题、内容摘要、数据接什么、图表用什么、布局放哪里。用户第一眼看到的是可确认的页面结构。

2. 模型改版态

用户只说“更像咨询报告、少字、多数据”。模型返回 operations，系统校验后更新 RGL 布局、Puck props、Recharts 配置和草稿内容。

3. 排队确认态

确认规划和视觉方向后，模型总结成生图 payload 入队。先出一张效果图，客户确认后再按草稿和数据渲染最终静态页。

原型说明：这是视觉和交互规划稿，不是正式实现。正式实现会把这些模块拆成 StaticPageDraft、react-grid-layout 画布、Puck Render、Recharts 图表和模型 operation 协议。
